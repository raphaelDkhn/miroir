# Contributing

Bug reports, questions and pull requests are welcome.

- **Bugs:** open an issue with the Miroir version, the manifest or task involved, and what
  `miroir check` printed.
- **Larger changes:** open an issue first, to agree on the approach before you write it.
- **Pull requests:** run the checks in [Develop Miroir](docs/src/develop.md#checks) before you
  push; CI runs them too, with the Docker integration tests. A change to the manifest, the task
  format, the tools or `check` updates the docs and [the skill](skills/miroir) in the same PR.

Report security issues as [SECURITY.md](SECURITY.md) says, not in public issues.
